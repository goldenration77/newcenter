Bio

Hello — I'm PixelRanger. I started making websites and pixel games on a Windows 98 box in the early 2000s and never really left that aesthetic behind. Today I ship indie games, retro-inspired web experiences, and tools for other creators. I care about clarity, craft, and interfaces that feel alive.

When I'm not coding I'm restoring CRTs, writing chiptunes, or collecting old manuals. This portfolio is a living demo of the UI language I love.
